# PG&E Statement Intelligence & Dashboard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a standalone data intelligence engine and interactive visual dashboard for PG&E statements that extracts billing, consumption, and TOU data from local PDFs and displays KPIs, monthly trends, and yearly comparisons.

**Architecture:** A standalone Python engine (`pge_intel.py`) parses statements in `Statements/*.pdf` using `pypdf` with regex extractors, writes structured outputs to `pge_bill_data.json` and `pge_bill_data.csv`, and renders an interactive, self-contained single-page dashboard (`dashboard.html`) with KPI cards, Chart.js visualizations, and a searchable statement table. Launchable via `view_dashboard.command`.

**Tech Stack:** Python 3, `pypdf`, Chart.js, HTML5, Vanilla CSS (dark theme, glassmorphism), vanilla JS.

**Spec:** [docs/superpowers/specs/2026-09-11-pge-intel-design.md](file:///Users/zany/Coding/Github/paperpull/docs/superpowers/specs/2026-09-11-pge-intel-design.md)

## Global Constraints
- Isolated to branch `pge-intel`; completely decoupled from `pge_docs.py`.
- Read-only: only operates on local PDFs in `Statements/`.
- Must not require external web servers; `dashboard.html` must open directly in any browser via `file://`.
- Must follow TDD: write failing unit tests before implementation.
